# ScreenGuard Android Agent v0.5.3

Initial maintainer-signed preview for Android 14+, compatible with the unmodified ScreenGuard server v0.10.17.

## Included

- Configurable WSS pairing and an Android Keystore-encrypted token.
- Local time accounting, shared quota synchronization and reconnect/offline recovery.
- Quota warnings, optional app blocking and parent PIN protection.
- Parent-to-child notifications and interface resources in six languages.
- Generic project documentation without personal server defaults.

## Limitations

Experimental software. Android can interrupt background services and optional Accessibility restrictions are not tamper-proof. Grant only permissions you understand. Not independently security-audited or validated on every Android device.

Independently developed under AGPL-3.0-or-later; not an official upstream ScreenGuard release.
