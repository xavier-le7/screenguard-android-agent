## Android adaptation

Exclude only intervals when a quota or app restriction overlay is actually shown, not a mere restrictive policy or Settings PIN prompt. Device, foreground-app and group ledgers share one local interval journal; subtract blocked spans during event replay and resume without backcharging. Parent recovery/essential apps remain available. Already-reported cumulative totals are not rewritten. The journal retains recent interval timestamps locally without application identifiers; abrupt process death can leave an unconfirmed tail of up to the normal confirmation interval under ordinary scheduling.

## Validation before release

- CI: unit tests and debug build; no signing credentials for review.
- Physical device: run allowed app, exhaust total time, leave overlay visible for at least 60 seconds, verify all three totals stop; grant extra time, verify only subsequent usage counts.
- Repeat for blocked individual app/group, 10-second grace, screen off/on, Home/essential app navigation, offline and reconnect, midnight, process restart and device reboot.
- Verify no persistent pause after failed overlay, Accessibility revocation or parent settings access; verify pairing, DNS toggle, remote logs, new-app approval and stable APK upgrade without uninstall.
- Compare actual server totals before and after each test. Do not promote this branch or create a release tag before physical-device validation.
