# Android Agent v0.10.18 — official release

- Numeric agent version 0.10.18, Android versionCode 21 (in-place upgrade from signed v0.5.3 / Android 0.10.18 TEST builds).
- Upstream fetch_logs -> log_response with limited, redacted app diagnostics.
- Per-application time reports and cumulative group usage to server v0.10.18.
- Per-group quotas with cross-device totals and accessibility enforcement.
- Durable new-app approval requests and server-side parent decisions.
- Safe notification for server-requested Android updates.
- Experimental parent-authorized DNS-only VPN for blocked domains.
- Explicit parent-PIN-protected start/stop controls; TUN descriptor closes
  immediately and stop persists across reboot/upgrade.
- Visible DNS state in the main health panel and settings.
- Live DNS VPN capability badge synchronized to server v0.10.18 via authenticated reconnect
  (upstream exposes availability, not a distinct active-status field).
- No change to Android app ID or stable signing certificate.

TEST3 was validated on an Android tablet before this public release. DNS-over-HTTPS/TLS and IPv6 routing bypasses remain known limitations of the optional DNS-only VPN. If a parent disables DNS filtering, it stays disabled after reboot; if enabled and VPN consent remains valid, the agent attempts automatic restart after reboot or APK upgrade.
